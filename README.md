# Bank Statement Information Extractor

An Android application developed in Java that extracts important information from bank statement PDFs.

## Features

- Select Bank (SBI, HDFC, ICICI, Citi, American Express)
- Upload Bank Statement PDF
- Extract:
  - Bank Name
  - Card
  - Last Billing Cycle
  - Payment Due Date
  - Total Amount Due

## Tech Stack

- Java
- Android Studio
- Gradle

## Run the Project

Open the project in Android Studio and run the application on an emulator or Android device.
